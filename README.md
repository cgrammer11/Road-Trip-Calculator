Road Trip Calculator & Stats Utility

A lightweight Command Line Interface (CLI) Python script that tracks vehicle data, computes fuel efficiency, and monitors daily travel velocity for road trips.

Features
- Calculates total distance driven using odometer milestones.
- Tracks fuel economy (MPG).
- Computes average pace per day.

How To Run
Ensure you have Python installed, then run the script via your terminal:
```bash
python main.py
```
